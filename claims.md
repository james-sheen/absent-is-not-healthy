# The technical report -- claims ledger

Every load-bearing factual assertion in `absent-is-not-healthy.md`, with the source that witnesses it and the check
that holds it. The project runs every row before each version; each check can also be run by hand, from this
directory:

- `file_contains:PATH::TEXT` -- the file holds the text;
- `file_matches:PATH::PATTERN` -- the file matches the regular expression, line anchors per line;
- `command:...` -- the command exits 0;
- `published_command:...` and `published_contains:URL::TEXT` -- the same, reaching the network: upstream at a
  pinned revision, or a published record.

A count is a claim about a revision, so the upstream rows measure `entity-manager` and `dbus-sensors` at the revisions
the report names, never a checkout that happens to be at hand. Two rows run appendix B's cases on the released engine
and score them; the nursing homes' takes about 15 minutes, so give the gate a timeout to match (`--timeout 1800`).
